# Simple Hand Gesture Recognition App

This is a small webcam app that detects a few basic hand gestures.

It is built to be simple, clean, and beginner-friendly.

## What it does
- Opens the webcam
- Detects your hand
- Shows the gesture on the screen
- Works with simple gestures like:
  - Open hand
  - Fist
  - Peace sign
  - One finger

## Install
Open the project folder in a terminal and run:

```bash
pip install -r requirements.txt
```

## Run
```bash
python src/app.py
```

Press Q to quit.

## File structure
- src/app.py - main app
- requirements.txt - needed dependency
- README.md - project info

## Very simple note
This project is intentionally minimal. It is a beginner-friendly hand gesture app, not a large machine learning system.
